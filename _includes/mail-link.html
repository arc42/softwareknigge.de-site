{%- comment -%} Spam-protected mailto link that also works by keyboard and touch. The address is assembled by script at load time, so it never appears in the HTML; without JavaScript the link shows the address in readable form. Label and subject are optional; each link keeps its own. Usage: {% include mail-link.html user="info" domain="arc42.de" label="E-Mail schreiben" subject="Betreff" %} {%- endcomment -%} {{ include.user }} (at) {{ include.domain | replace: '.', ' (punkt) ' }}
